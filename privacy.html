台股研究報告助手 隱私權政策

最後更新：2026 年 9 月 29 日。

本政策說明「台股研究報告助手」的 Gmail 報告寄送功能如何處理資料。本工具由個人管理者維護，供其本人使用。

處理哪些資料

  • 帳戶持有人同意提供的 Gmail 寄信授權，包括供後續寄送使用的授權憑證。
  • 管理者設定的寄件地址、收件地址，以及本工具產生的郵件標題、內文與 PDF 報告附件。
  • 寄送時間、作業結果與識別碼雜湊等必要紀錄，用於追蹤失敗與避免重複寄送。

本工具僅申請 Gmail 寄信權限（gmail.send），不讀取收件匣、既有信件及其附件或通訊錄，也不刪除信件。Google 密碼在 Google 的授權頁面輸入，本工具不取得該密碼。

使用目的與分享對象

授權資料僅用來取得寄信所需的存取權限。報告內容及郵件地址會傳送至 Google Gmail 服務，再交付管理者指定的收件者；寄送紀錄用於作業診斷。報告可能含管理者輸入的個人投資資訊，因此收件地址由管理者自行設定。

本工具不將 Google 使用者資料出售、用於廣告投放或訓練通用人工智慧模型。對 Google API 資料的使用與轉移，應遵循 Google API Services User Data Policy，包括 Limited Use 要求。

保存與保護

授權憑證保存在管理者控制的私人執行環境，使用限制檔案存取權限保護；與 Google 的傳輸使用 HTTPS。短期存取權杖僅供程式於記憶體內使用，不寫入報告。

本工具會保存本機報告與作業紀錄，供管理者追查歷史結果。這些檔案目前沒有自動刪除期限，保留至管理者確認刪除。已寄出的郵件及收件者保留的副本，另受 Gmail 服務及收件者的保存方式影響。

公開說明網站

本說明網站不設登入、資料輸入表單或分析追蹤程式，也不接收 Gmail 授權憑證或私人報告。網站發布於 GitHub Pages 時，代管服務可能為維運及安全目的處理 IP 位址等連線資訊，請參閱 GitHub 隱私權聲明。

撤銷授權與刪除資料

您可前往 Google 帳戶的第三方連線設定撤銷本工具的存取權。撤銷授權會停止後續使用該授權寄信，但不會自動刪除本機報告或已寄出的郵件。

如需移除私人環境中的授權檔、報告或作業紀錄，請聯絡管理者，由管理者確認範圍並處理。已交付收件者的郵件副本需由各持有人另外管理。

政策更新與聯絡方式

若資料用途或權限範圍變更，管理者會更新本政策；需要額外 Google 權限時，另行取得帳戶持有人同意。
